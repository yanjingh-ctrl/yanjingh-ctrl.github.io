# Jinghong Yan Portfolio

A responsive bilingual portfolio website built from Jinghong Yan's research presentation and résumé.

## Preview locally

Open `index.html` directly, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

Upload the full folder to GitHub and enable GitHub Pages from the repository root, or drag the folder into Netlify Drop.

## Easy updates

- Replace `assets/profile-photo.png` if a portrait is added later.
- The confirmed LinkedIn link is included in the hero and contact sections.
- Replace the downloadable résumé or presentation while keeping their filenames unchanged.


## Project case studies (November 2026)

Expanded Quadruped Robot and RoboSub AUV case studies with original CAD, fabrication, test, and FEA images from project reports. All project image assets are in `assets/projects/`. English/Chinese toggling remains supported.
